# Satoshi font files

These WOFF2 files are self-hosted copies downloaded from the official Fontshare CDN:

- `satoshi-light.woff2` — weight 300
- `satoshi-regular.woff2` — weight 400
- `satoshi-medium.woff2` — weight 500

Satoshi is distributed by Fontshare under the ITF Free Font License. Review the current terms before redistribution: <https://www.fontshare.com/licenses/itf-ffl>.

Font loading is configured in `app/layout.tsx`. The application makes no runtime request to Fontshare.
